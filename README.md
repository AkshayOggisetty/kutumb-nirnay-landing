# Kutumb Nirnay — landing page

Marketing site for **Kutumb Nirnay**, a career counselling and decision-support
platform built for the household rather than the student alone.

**Live:** https://akshayoggisetty.github.io/kutumb-nirnay-landing/
**Prototype:** https://akshayoggisetty.github.io/kutumb-nirnay/
**Prototype source:** https://github.com/AkshayOggisetty/kutumb-nirnay

Single self-contained `index.html` — no build step, no dependencies, no trackers.
Type and colour tokens match the prototype so the two read as one product.

Design and content by Ishita Choudhary.
